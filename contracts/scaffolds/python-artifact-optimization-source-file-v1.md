# Python source-file optimization

Write one complete Cake Python Schedule in `candidate.py`. Keep the frozen Workload,
tensor ABI, exact target and lowering route. Each Turn may submit one candidate;
update the same file in later Turns with one explicit optimization hypothesis.
The Lab seals your original UTF-8 source and creates its own candidate transport.
Do not write Schedule/Program JSON or a transform request in this treatment.

Use the exact Target's instruction contracts and execution-group width. Static
analysis and generated code are feedback, not correctness or speed evidence. The
Lab owns compilation, GPU allocation, the external oracle, paired timing and
profiler attribution. Report only the candidate and hypothesis you wrote;
confirmation and scientific claims belong to the retained Evaluation.
