## 2026-10-09：补齐十题初始实现与评测入口

Bench 继续固定 `ababa4c0`。实验集成源码为 `3cc84f3b`，对应 [PR #402](https://github.com/qhy991/open-cake-ir/pull/402)。它含十题的初始 CAKE 实现；固定源码下的 48 项 CPU 合同通过。Decoder 含 33 个输入、10 个输出、22 个阶段，原始 16 形状的 352 个叶 Schedule 均可降级。设备验收按题单独推进。

| 验证范围 | 当前证据 | 下一步 |
|---|---|---|
| 原 Bench 的设备环境与参考实现 | 十题共 1600/1600 原参考自检通过 | 检查 CAKE 候选 |
| 多阶段 Program 测量组件 | 同一四阶段候选的单次 A/A 通过；每臂 10 个事件样本；另有四阶段 profile | 每题固定基线独立验收 |
| 原始 RoPE 候选 | 16 个形状原生编译通过；原检查执行 11 次，10 次通过，在第二形状首轮停止 | 对齐参考的 FP32 矩阵乘法数值语义 |
| 三小时 Ralph 搜索 | 新 Bench 搜索尚未启动 | 完整正确性、基线及 provider 门通过后启动 |

RoPE 的单例诊断将误差定位到角度计算：CAKE 与逐元素 FP32 角度版本的 524,288 个 BF16 输出完全一致；原参考在当前允许 TF32 的环境中通过矩阵乘法生成角度，两者不满足原比较器。该记录保留为失败，不更改原 oracle 或容差。它没有证明三角函数指令存在缺陷，也没有资格化 C550 的 TF32 指令路径。[完整检查入口](https://github.com/qhy991/open-cake-ir/pull/437)

多阶段题目的最终验收由原 Bench 生成完整的 16×10 输入序列。正在补齐只加载封存原生代码、返回 Tensor 的薄适配器；重复同一 seed 的单例检查不能替代该序列。

每题仍共享三小时：16 个形状的搜索与各自确认共 9720 秒，完整原 Bench 复验预留 1080 秒。性能基线将是该题在本轮源码和工具链下封存、通过验收的初始 CAKE 实现；原 Torch 参考当前只负责正确性，不是已测量的加速比分母。以上结果尚无 Bench 性能收益结论。

## 2026-10-10：原始正确性通过，计时入口继续验收

公共集成源码为 `51063d2e`；本机后继含独立的主机记录，实际 Compiler/Executor 提交为 `affdd3951`。同一后继通过 40 项 CPU 合同、原 Corpus 204 项、16 个 RMS 原生基线构建及其绑定检查。原 RMS 的 **16×10 正确性再次完整通过**（job `maca-29800abbdf8e`）。最大绝对误差 0.0625、最大相对误差约 0.01389，均由原比较器按原容差判为通过；这不是逐位相同的声明。

前版 `0c8ef54e` 的首次公共 A/A 在第一次候选调用后发生 `KeyError: 0`，没有计时样本或有效收据，后续十五例未提交。原 Bench API 将公共框架的只读命名映射误判为位置序列。后继只在这个 API 边界浅转为普通字典，Tensor 对象、原比较器及容差保持不变；20 项 Linux 合同和原故障的 CPU 复播通过。[修复与完整范围](https://github.com/qhy991/open-cake-ir/pull/449) · [Finding](../../../findings/2026-10-10-004-c550-bench-mapping-boundary.json)。旧失败仍为失败，后继计时资格单独记录。

RoPE 还有一条数值机制线索：三个原始形状保留的 409,984 个角度输出词中，当前 BLAS HIGH 结果逐位符合 RNE10 操作数模型，当前 Triton TF32 结果逐位符合 RTZ10 模型。该数量是输出词数，不是独立实验次数。它解释了本次替换失败，未授权生产 TF32 准入。[有界探针](https://github.com/qhy991/open-cake-ir/pull/443)。

新的 RoPE 候选显式保留所需的频率舍入：在已证明的输入范围内，使用 FP16 的舍入和精确二次幂缩放；它复用现有 IR 和已支持的转换操作。CPU 边界证明、反例和源码检查已通过，原始设备验收仍单独进行。[候选及适用域](https://github.com/qhy991/open-cake-ir/pull/446) · [原始验收入口](https://github.com/qhy991/open-cake-ir/pull/447)。

以上均属于任务接入、协议修复和固定候选资格。正式 Agent 搜索及性能结果尚未产生，不据此声称 Compiler 泛化收益。
