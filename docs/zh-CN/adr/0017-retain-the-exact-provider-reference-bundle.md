# ADR 0017：保存每轮真正给 AI 的参考材料

[设计目录](README.md) · [英文决定](../../adr/0017-retain-the-exact-provider-reference-bundle.md)

**原文状态：已接受，2026-08-24。**

只保存“准备给 AI 哪个文件”的路径，不能让别人确认 AI 实际看到了什么。因此原文中的后继 Executor 保存每轮渲染后的完整 UTF-8 参考包，作为 `provider_reference_bundle` 证据对象。

事实仍由 Workload、Study、Compiler 和写作环境负责。`CodexRunProvider` 返回实际用于该轮的字节，Lab 写进已有证据存储并由完成事件引用。相同内容可复用同一存储对象；内容身份不是第二份参考政策，也不自动证明没有实现污染。

适用后继规则时，每个完成轮恰好需要一份有效参考包。缺失、空内容或非 UTF-8 时，Lab 记录已消费 token，并在接收候选前封存 `harness_fault`，终点缺失；不能把缺资料算成通过污染审计。

原文 v24 及更早的 Run 没保存该对象，仍按历史边界回放，不补造对象或结论。验收检查首次与继续轮实际渲染字节、每轮归档与回放，以及故意遗漏包时的可重放故障。
