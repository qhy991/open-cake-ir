# ADR 0015：AI 推理强度也是实验条件

[设计目录](README.md) · [英文决定](../../adr/0015-reasoning-effort-is-treatment.md)

**原文状态：已接受，2026-08-24。**

用同一个模型却给不同思考强度，仍可能改变实验结果。两边必须固定相同 `reasoning_effort`，并由真实 provider 资格证明该确切配置；没有隐含默认值。

正式字段是 `study.arms.*.provider.reasoning_effort`。资格把它与模型、服务档位、输出格式、沙箱、参考、功能策略和提交方式一起绑定；CampaignLock 保存相同 provider 配置，首次与继续调用都发出同一个值。

Lab 检查非空配置和资格是否匹配，不另维护一张可用强度表；实际支持由已经检验的工具版本决定。把旧 `max` 改成 `xhigh` 而不换资格，会在运行前被拒绝。

旧实验保留 `max` 的原义，不能称作论文 `xhigh`。未来需要该条件时，先真实资格，再固定后继 Study。验收要观察准确调用参数，验证两边继承相同配置，并拒绝没有新资格的单纯改字段。此决定不需要新管理代理，也不导入 KDA 的运行框架。
