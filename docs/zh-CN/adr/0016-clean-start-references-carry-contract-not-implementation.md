# ADR 0016：从头探索只给题目接口，不给现成答案

[设计目录](README.md) · [英文决定](../../adr/0016-clean-start-references-carry-contract-not-implementation.md)

**原文状态：已接受，2026-08-24。**

若想研究作者能否从头发现方案，参考里不能藏着已经写好的目标实现。Cake starter 只给外部 Buffer 和输出，没有线程映射、角色、临时分配、流水线、同步或操作；CUDA starter 给启动接口和函数签名，函数主体为空。

两个参考必须作为一次后继操作一起更换，不能只改变一边。Workload 仍定义数学，CUDA 启动约定定义参数接口，Compiler 定义完整计划；starter 只是这些依据的投影，Study 固定真正嵌入每轮的字节。

Cake starter 故意还不是有效 Schedule；作者完成实现前会被拒绝。CUDA 的启动说明可解析，但空函数无法通过外部正确性。Lab 始终独立评分，作者只交封存候选集合。

验收要拒绝单边替换、Cake 结构字段中的实现和 CUDA 非空主体。旧有完整骨架的实验保留“已经得到任务经验”的含义。此夹具当时仍是本地 150k/`max` 条件，只解决参考访问，不自动成为论文对齐实验。回退也创建后继，不修改旧证据。
