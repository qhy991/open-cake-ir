# ADR 0050：发布过的编译器 lock 也永久保留身份

[设计目录](README.md) · [英文原文与完整证据](../../adr/0050-released-compiler-locks-reserve-their-identities.md)

**原文状态：已接受，2026-09-06。**

原文 v41 已被 FMA 任务使用，本地引用扫描却只找到 v40。若照旧逻辑发布，会把新源码仍叫 v41。增加几个搜索目录也无法证明外部没消费者。

发布 lock 本身保留版本身份。绑定源码变化时先归档旧版，在当前和已知历史序号之上准备后继。批准和验证前保留旧 lock、旧批准；重复准备沿用同一 draft。已发布内容完全匹配时再运行是无操作，不产生新版本，不回收发布归档。

历史 GPU 任务从完整 Git 源码版本回放，不能要求今天的主线兼容所有旧 lock。文档修正也不重新标注旧 GPU 成绩。

验收覆盖无本地引用的已发布 lock、重复未批准准备、独立批准后的后继和未改发布核验，并要求先前四份发布依据保留。此规则不移除明确批准输入，也不改 IR 语义。
