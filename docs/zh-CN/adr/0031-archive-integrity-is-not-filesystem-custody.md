# ADR 0031：文件完整，不等于保管过程可信

[设计目录](README.md) · [英文原文与完整证据](../../adr/0031-archive-integrity-is-not-filesystem-custody.md)

**原文记录日期：2026-08-25；具体当时执行器状态见原文。**

归档像装订好的实验本。`archive_integrity` 检查依据、事件链、终态和引用内容是否构成完整 Run；`filesystem_custody_verified` 检查读到的目录和文件是否满足拥有者、权限和单写入者要求。

一个允许其他人修改的 Git 拷贝，可以完整但保管未验证。仍允许检查和语义回放，却不能支持候选晋升、系统资格或科学估计。今天把权限改严，也不能证明过去一直没人能改。

`EvidenceStore.audit_run` 一次产生两种事实，Lab 聚合，消费者不各算一遍。读取仍不沿链接越界；写入入口继续严格检查保管，不因只读能看而放宽。

缺文件、非法链接、乱序、格式或内容不符使完整性失败；正确字节配宽松权限则只让保管失败。验收要同时覆盖宽松历史拷贝可读但不可写、改内容导致完整性失败、正常活跃存储两项通过。不加新归档格式或权限清单，不重解释旧记录。
