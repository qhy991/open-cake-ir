# ADR 0049：发布过的执行器身份，即使本地没人引用也不能复用

[设计目录](README.md) · [英文原文与完整证据](../../adr/0049-released-executor-descriptors-reserve-their-identities.md)

**原文状态：已接受，2026-09-06；取代 Executor 按本地引用回收身份的规则。**

分支审查发现同名 v41/v42 在不同历史绑定了 45 与 43 个源码。旧脚本只扫描本地实验和清单，没看到引用就删描述、复用名字。但远端可能早已使用，本地扫描无法证明“没人用过”。

已发布 descriptor 本身就保留身份。发布流程读取 `runtime/executors` 和归档 `evidence/executors` 的同一描述集合，保留每份发布文件，在最大序号之后产生下一版。清单只是阅读投影，没有引用不能授权回收。不同历史绑定原提交，整合时不能互相覆盖描述文件。

旧主机不存在时，可由发布操作人员提供已核验主机的 `--host-environment` JSON。脚本只检查结构并保留内容，不把结构有效说成亲自验证了活主机；未提供时仍用已有发现路径。

回归验收实际做两次无本地消费者的发布，并纳入更高序号归档，确认序号增加、旧字节保留、清单历史保留。此决定不改 Compiler 发布批准规则。
