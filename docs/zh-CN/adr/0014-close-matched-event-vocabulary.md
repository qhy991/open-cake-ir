# ADR 0014：实验事件只能使用约定的词汇

[设计目录](README.md) · [英文决定](../../adr/0014-close-matched-event-vocabulary.md)

**原文状态：已接受，2026-08-24。**

如果审计遇到一个不认识的事件还直接跳过，就可能漏掉改变结论的行为。后继 Study 因此固定 `study.evidence.event_vocabulary=matched_run_v1`，CampaignLock 保存同一选择；这不是调用者可扩展的事件注册表。

第一个事件必须是唯一的 `run_started`，顺序和环境来自预定分配。唯一的 `checkpoints_projected` 紧接唯一终态之前，其余事件属于某轮或终态故障。

`candidate_set_filtered.order` 负责候选处置、可用发布成本和语义身份。相同程序合并、成本模型问题的诊断，都必须由该顺序、合格搜索收据、固定阈值推导；`diagnosis_routed` 不能成为另一个任意填写的事实。

未知类型、重复边界、改过的开场、额外字段、无依据对象或诊断都让语义回放失败。内容完整与保管可信仍是另外两项。旧实验通过有界兼容按旧行为读取，后继不能重新生成开放词汇。

验收先让完整 Run 在新进程回放，再分别注入未知事件、改开场、改诊断，三者都必须被拒绝。没有为此改变存储格式、添加活动时间或在审计时重新跑编译器。
