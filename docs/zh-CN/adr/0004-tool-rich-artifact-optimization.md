# ADR 0004：丰富的 AI 工具用于单产物优化

[设计目录](README.md) · [英文决定](../../adr/0004-tool-rich-artifact-optimization.md)

**原文状态：已接受，2026-08-23。** 后继任务文件接口见 [0048](0048-agent-runs-use-task-agents-and-ralph-control.md)。

研究比较需要受控环境；工程优化关心能否得到一个确认合格的好程序，可能需要更多工具。因此在已有 `matched_search` 路径增加 `artifact_optimization_only` 声明范围，不增加运行模式。

每种环境各一个 Run，可以有界多轮尝试。每个 Run 只选确认合格且延迟最低的候选；并列取更早的轮次。没有组间比较、汇总估计或科学纳入。成为 KernelSeed 还需要后续明确冻结。

`disabled_features=[]` 只表示项目不额外禁用功能，实际功能仍由固定工具版本、账号和管理策略决定，需要单独的真实资格检查。辅助活动保存为有类型的事件和原始记录；模型自己报告的工具次数不能作为事实来源。

多个工具可以帮助写程序，但候选只有一个主要提交者，正确性与晋升只来自共同评测。工具可见不等于获准改外部系统或直接测 GPU。原文中的临时文件规则属于当时接口；后继两文件协议按 0048 执行。多代理用量仍按 provider 的轮末报告，最大轮数另设硬上限，不能据此声明科学 token 预算效果。
