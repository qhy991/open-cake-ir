# ADR 0021：top-k 同时返回数值和原位置

[设计目录](README.md) · [英文原文与完整证据](../../adr/0021-top-k-is-a-deterministic-indexed-selection-primitive.md)

**原文状态：已接受，2026-08-25。初始 FP32 范围的后继扩展见 [0041](0041-resident-top-k-supports-signed-int32.md)。**

`top_k(source[n], k)` 在寄存器里的一维数据中选最大的 k 项，同时返回数值和 INT32 原位置。例如 `[5, 9, 9, 2]` 取两个，结果是数值 `[9, 9]`、位置 `[1, 2]`：数值降序，相同值取较小位置在前。

初始输入是 FP32，`1 <= k <= n`，k 编写时固定，不接受 NaN。恰好一个读取、两个有顺序的输出，先数值后位置，形状都为 `[k]`，不能与读取别名。Triton 当时只生成 k 为 2 的幂的情况；这是后端限制，不是数学定义限制。

初始生成方式重复找最大值和最小符合位置，并单独标记已选位置。不能只把选中值改成负无穷，否则输入本来含负无穷时可能重复选同一项。这个实现可以检查，但没声称最优，也不暗藏另一算法选择。

验收覆盖类型、数量、形状、k、并列、源码、完整语料和 B200 独立稳定排序参考；保存的反例把结果形状写小，必须拒绝。它不包含分组、路由、权重归一化、scatter 或完整 KDA。静态寄存器解释以后还需结合 [0039 的修正](0039-logical-register-pressure-is-not-a-physical-bound.md)。
