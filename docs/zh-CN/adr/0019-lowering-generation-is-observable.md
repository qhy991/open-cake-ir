# ADR 0019：生成的代码与选出的固定代码要分清

[设计目录](README.md) · [英文原文与完整证据](../../adr/0019-lowering-generation-is-observable.md)

**原文状态：已接受，2026-08-24。**

`Lowering.generated` 明确回答“这段源码是否由计划中的操作生成”。后端真正生成源码时是 `true`；选择一个封闭固定源码、只代入计划身份时是 `false`。CLI 和新观察直接展示这个字段，不能凭文件名或后端语言猜。

像“根据图纸加工一个零件”和“从仓库取出已经做好的零件”，都可能得到可用产物，但证明的能力不同。TinyGEMM2 保留固定源码能力，却不能因此声称计划已经表达生成该内核所需的线程、地址和循环细节。

当时已有的后端／固定资产选择负责这一事实，`Compiler.lower` 原样投影。验收要求生成路线为真、TinyGEMM2 为假、CLI 一致，已有源码内容不变。后继路线归属见 [0029](0029-lowering-route-is-not-a-workload-profile.md)。
