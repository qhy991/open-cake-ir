# ADR 0041：驻留 top-k 可以按有符号 INT32 排序

[设计目录](README.md) · [英文原文与完整证据](../../adr/0041-resident-top-k-supports-signed-int32.md)

**原文状态：提案。**

已经选出的整数块号需要重排，以改善后续数据访问。top-k 已有排序与并列规则，只是初始仅收 FP32；把整数先转成浮点会额外引入转换问题。

提案让一维驻留 top-k 接受 FP32 或有符号 INT32。返回值保持原类型，原位置仍为 INT32。整数按通常的有符号降序，相同值先取较小来源位置；已有 NaN 参数对整数不产生实际条件。

后端翻转符号位，把整数映射成单调无符号顺序，与并列键打包到 UINT64，经 `tl.topk` 后恢复原值和位置。作者仍只写 top-k，不新增 sort、整数 cast 或布局概念。

INT32 的 `across_loop` 明确不支持，以 `TOP_K_INT32_ACROSS_LOOP_UNLOWERABLE` 阻止；其他类型、形状、寄存器放置、k 和二次幂要求保持。验收包含负哨兵正例、跨循环反例、旧 FP32 源码不变、单独预期审查和完整发布门槛。正确性和性能还得由外部 GPU 证据回答。
