# ADR 0005：按材料生命周期整理，保留旧路径

[设计目录](README.md) · [英文决定](../../adr/0005-forward-compatible-lifecycle-layout.md)

**原文状态：已接受，2026-08-23；其中下一版描述文件的搬迁承诺已被 [0007](0007-candidate-evidence-and-revision-witnesses.md) 取代。**

源码、固定合同、发布描述、实验记录和当前视图的更新方式不同。历史文件却常被精确路径和内容引用，不能为了目录好看就搬动。

决定保留历史字节与路径，新材料在后继边界逐步按生命周期放置：实现放 `src/`，不可变定义有明确模块负责，发布描述与定义分开，历史证据不可改，当前报告可以重建。具体负责人先在模块职责中决定，不能靠“放进哪个文件夹”暗中分配。

新的 CampaignLock 和 Evidence 根目录必须在 checkout 之外，只创建新内容。CLI 和 Lab 公共接口都检查这点；旧仓库内实验仍可只读审计。

原文设想的 `definitions/`、`releases/` 是迁移方向，不是今天必然存在的路径。后来的 0007 保留已有正式版本路径，避免搬迁制造双重可写依据。目录和结论视图只供查找，不能选择执行器、授权实验或改变运行状态；跨版本共用存储也要等真实需求证明值得增加管理复杂度。
