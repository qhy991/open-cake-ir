# ADR 0011：校准真实的“三选二”决定

[设计目录](README.md) · [英文决定与测量](../../adr/0011-finite-domain-ranking-calibration.md)

Lab 一轮写三个候选、只测两个时，排序的真实作用是删掉一个。校准应回答：会不会删掉比留下者快超过 `5%` 的方案？不能只说预测值和时间“看起来有关”。

原计划预先固定 30 个候选、编译器与评测源码、两次独立测量和判定规则。只读检查器先核对保管与范围完整，再枚举所有可用三成员组合。只有零、一、两个候选时，无须截断。

错误候选、缺行、来源不符、遗漏可排序行、重复测量，或任何组合超过 `5%` 损失，都使校准失败。混合了已测和未测候选时，整个集合保持作者顺序；不能把已测者排前面，变相删掉未知者。

历史两轮分别在独占 GPU 上为每个正确候选取得 41 个冷 L2 样本，各有 25 个正确测量候选、5 个编译器拒绝，覆盖 `2,300` 个三选二决定。最坏损失为 `35.95%`、`8.16%`，两轮均失败。原始记录保留，发布覆盖不变。即使未来通过，也只支持后续审查的精确范围，不支持整个算子名称下的所有形状。
