# ADR 0032：访问边界由真正被访问的数组决定

[设计目录](README.md) · [英文原文与完整证据](../../adr/0032-access-boundaries-use-the-accessed-buffer.md)

**原文状态：已接受，2026-08-25。**

矩阵有 256 项，偏置却只有 128 项。即使两者使用同一个坐标，也不能按矩阵的 256 上界读取偏置，否则会越界。

每个 `mask_tiled_axes` 坐标必须和被访问的全局 Buffer 对应维度比较。ProgramAxis、TileLoop 仍负责分工、块宽和循环次数，但不拥有另一个数组的长度。AccessMap 的坐标与该 Buffer 的 `shape` 是访问边界依据。

短偏置按既有加载规则在越界部分补零，是合法计划语义；是否符合某个数学题目另由 Workload 判定。原文正例要求生成 `n_block_offsets < D_BIAS_0`，其中偏置长度 128；独立参考也对缺失部分补零。

验收检查掩码负责人、CPU 结果审计、完整 Corpus 差异和后继 B200 比较。旧 v24 已有在设备上的观察，因此修复必须是编译器后继，不改旧源码或放宽数值容差。此决定没有新增 IR 操作或性能结论。
