# ADR 0013：没找到好方案，与没有拿到有效数据要分开

[设计目录](README.md) · [英文决定](../../adr/0013-two-part-scientific-estimand.md)

**原文状态：已接受，2026-08-24。**

像考试交白卷和试卷在运输中丢失，二者不能记成同一种情况。遵守协议但没找到合格候选，是观察到的负结果；AI、评测框架、保管或调度故障，是缺失数据。

后继科学分析分两部分：到终点预算时的合格率，以及在合格条件下的确认延迟。`budget.limit` 独自拥有预算数值，`allocation.order` 拥有预定 Run，`run_inclusion` 决定哪些观察进入哪部分。

完整估计要求预定终点全部存在，且每边至少一个合格 Run。估计包含 `open_cake_rate - direct_cuda_rate`、两边合格者延迟中位数，以及 `direct_cuda_median / open_cake_median`。某些正常失败可以存在；一边完全没有合格者时，条件延迟无定义，完整估计不可用。

报告分别列预定、观察、合格、缺失数量。描述性合格率以已观察终点为分母，必须这样命名；科学估计还需完整性、保管、语义回放和零缺失通过。

验收包含全合格、有正常失败但两边仍有合格者、一次外部故障三种情况。旧计划保留原先“全部合格”的规则，不被新规则重解释；此决定没有补值、替补 Run 或新增推断统计的方法。
