# ADR 0047：稳定规则、旧记录和当前状态分开维护

[设计目录](README.md) · [英文原文与完整证据](../../adr/0047-documentation-separates-stable-history-and-current-views.md)

**原文状态：仓库拥有者已接受，2026-08-30。只改变文档职责。**

同一个版本号写在 README、教程和多篇报告里，更新一次就可能有几份忘改。解决办法是每个事实只有一个正式负责位置，其他页面链接或生成。

五类材料的规则：稳定说明随支持约定变化；决定历史用后继 ADR；合同和发布版本走自己的后继流程；某日观察冻结、纠正另写；当前视图由正式依据生成，可以删除重建，不能自己授权或产生结论。

`docs/GLOSSARY.md` 统一定义术语，各模块说明只解释职责并引用它。README 链到状态和机器可读依据，不手写发布历史或成绩账本。没有统一已接受 Study Report 索引之前，状态页只报告发布依据，不汇总全项目研究结论。

使用可理解的能力名称，旧迁移编号只在固定身份、路径或明确历史引用中保留。新候选、评测、实验与报告只追加证据；反复证据改变了稳定约定时才改稳定文档。历史路径不能只为整齐而搬走。

验收检查入口无手写版本账本、生成状态与正式文件一致、词义没有平行定义、门槛标题说清能力，并有文档检查捕获漂移。这条规则同样适用于中文、英文阅读页；翻译不产生第二套合同。
