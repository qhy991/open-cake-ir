# FMA v41 发布审查：静态版本正式完成

**历史发布记录：2026-09-04。本文不能替代实际批准文件。**

四个 FMA 正反例经审查加入唯一 Corpus manifest，完整 Gate `72/72`、91 个绑定源码。独立技术结论为 `recommend-static-release`，随后按用户一次明确授权记录精确 Gate 批准，既有流程成功发布 v41，v40 归档保留。

审查者独立重跑 15 项 CPU FMA 合同（未重复会写缓存的编译项），构造 89 个公共 assess 探测，其中 67 个可解析，覆盖类型、存储、形状、读写、指令、后端／目标和合法复用，无异常或意外结果；另查七种嵌套依赖，确认四个新例子的预期。

最后重新构建 Gate，确认旧 68 项和非 case 字段未变，四项恰好是审查过的提案。最初把带换行文件的字节摘要误当规范化 JSON 的 Gate 身份，发布正确退出 3；纠正身份记录并独立复核同一 Gate 后才成功，没有改源码或预期来让发布通过。

正式版远端相关测试 `252/252` 无排除，包括先前只能在 v40 上跑的五项身份测试。两次真实 GPU-free 编译再次通过；独立审查者返回 `verified-release`，确认正式 lock、批准、全部源码及 Gate 关系。

这条记录只证明 IR 静态语义、验证、分析、生成和发布。取消误差、符号零、次正规数、Inf/NaN 和嵌套 FMA 的 GPU 完整输出当时仍需独立任务；后来的[数值检查](AKA_FMA_B200_CORRECTNESS_20260904.md)单独记录。log/cos 不属于 v41 实现，本次记录没有 main 合并或性能结果。
